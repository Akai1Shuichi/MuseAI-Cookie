# Muse Cookies (Chrome extension)

Xuất / nhập cookie muse.ai dạng chuỗi: `hatch_sess=...; datr=...; hatch_native_auth_device=...`

## Cài đặt

1. Mở `chrome://extensions`, bật **Developer mode**.
2. **Load unpacked** → chọn thư mục `extensions/muse-cookies`.

## Dùng

- **Xuất (copy)**: lấy cookie muse.ai đang đăng nhập, hiện trong ô và copy vào clipboard.
- **Nhập**: dán chuỗi vào ô → bấm **Nhập**. Cookie muse.ai cũ bị thay, tab muse.ai đang mở được tải lại.

Cookie là phiên đăng nhập: ai có chuỗi này là vào được tài khoản. Đừng chia sẻ.
